# Hospitality Analysis – Power BI Dashboard

This repository contains my end-to-end Power BI dashboard project analyzing hospitality performance across revenue, bookings, occupancy, cancellations, and customer ratings for AtliQ Hospitality’s portfolio of properties.

## Project Overview

AtliQ Hospitality, operating multiple hotels across various cities, needed a consolidated reporting solution to overcome scattered Excel-based systems for bookings, revenue, and customer insights. This dashboard unifies fragmented data and empowers real-time, data-driven decision-making.

## Dashboard Features

- **Overall Analysis:**  
  Key KPIs including Revenue, Occupancy %, Cancellation Rate, Average Rating, and Total Bookings—filterable by city, property, and booking platform.
- **Revenue Analysis:**  
  Revenue breakdown by city, property, room category, and platform. Highlights trends, identifies high-value customers (Elite), and pinpoints top-performing room types.
- **Booking Analysis:**  
  Deep dive into booking success, cancellations, occupancy, and usage patterns by day, month, and booking source.
- **Rating Analysis:**  
  Visualization of customer ratings by property, room class, and time. Highlights best and underperforming locations for targeted improvement.

## Key Insights

- Elite room class and RT2 room type accounted for the highest revenues.
- Weekends and end-of-month showed significant occupancy and revenue shifts.
- Booking platforms like makeyourtrip and logtrip were top revenue drivers.
- Atliq Blu achieved the highest average customer rating, while Atliq Seasons highlighted areas for service enhancement.
- June saw peak cancellation rates, impacting occupancy.

## Technologies Used

- Power BI Desktop (.pbix)
- DAX for calculated measures and KPIs
- Power Query for ETL and data modeling
- Interactive dashboards with slicers and drill-throughs
- Conditional formatting for high-impact visualization
